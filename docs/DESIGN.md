# デザイン方針

## 参照

`C:\Users\notab\Documents\New project\projects\servicenow-nttsmc-customer-portal` の業務ポータル感を参照し、学校現場向けの静かな作業台に翻訳する。

## トーン

- 先生が授業前後に短時間で扱える、落ち着いた実務画面にする。
- マーケティング風のヒーローではなく、最初の画面から名簿、教室、座席表、履歴が見える構成にする。
- 枠線、淡い面、状態ピルを中心にし、強い影や装飾背景を避ける。

## カラー

- Primary: `#005BAC`
- Accent: `#008C95`
- Surface: `#FFFFFF`
- Muted surface: `#F5F9FC`
- Border: `#D7E1EA`
- Ink: `#162033`
- Success: `#137333`
- Warning: `#A16207`
- Danger: `#B3261E`

## コンポーネント

- 主要操作はアイコン付きボタンにする。
- 座席は固定寸法のタイルで、名前、座席番号、配慮タグ、固定状態を収める。
- 重要な状態は色だけに頼らず、テキストでも示す。
- 印刷時は操作レールを隠し、座席表をA4に寄せる。

## アクセシビリティ

- フォーカスリングを明示する。
- 日本語の長い名前やメモは折り返せるようにする。
- モバイルでは左右レールを縦に積み、座席グリッドは横スクロールで崩れを避ける。
