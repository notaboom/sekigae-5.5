# プライバシーとデータ扱い

## 既定動作

- 児童名、配慮メモ、座席履歴はブラウザの `localStorage` に保存される。
- GitHub Pages版も静的ファイルとして配信され、アプリ側から外部サーバーへ児童データを送信しない。
- JSON/CSV/印刷は利用者の端末上で作成される。

## 注意点

- 共有端末では、作業後にブラウザデータを削除するか、JSON保存後にリセットする。
- 実名や配慮内容を含むJSON/CSVは、学校の運用ルールに従って管理する。
- 今後クラウド同期を追加する場合は、既定OFF、明示的な保存先、認証、削除方法をREADMEに追加する。

## 公開リポジトリに含めないもの

- 実際の児童名簿
- `.env`
- 個人情報を含むJSON/CSV
- 検証中に作ったスクリーンショットや一時出力
