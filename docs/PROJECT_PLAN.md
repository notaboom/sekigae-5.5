# 実装計画

## 目的

小学校の先生が、児童の配慮条件と過去の席替え履歴を見ながら、偏りの少ない座席案を素早く作成できるWebアプリを新規に作成する。

## 前提

- 旧 `https://github.com/notaboom/sekigae` は機能参照としてのみ使う。
- 新アプリは静的Webアプリとして公開し、既定ではサーバーや外部DBへ児童情報を送らない。
- 先生がブラウザ上で操作し、端末内保存、JSONバックアップ、CSV、印刷で運用できるようにする。
- GitHubリポジトリはグローバル公開を目的として public にする。

## 完了条件

- 名簿を追加、編集、CSV/TSV貼り付けできる。
- 教室の行列、使用不可席、固定席を設定できる。
- 視力配慮、身長配慮、履歴上の同席/同隣、任意の男女ペア配慮を使って席替えを生成できる。
- 生成結果を履歴として保存し、過去と同じ左右ペアを見える化できる。
- JSON保存/読込、名簿CSV、座席CSV、A4印刷が使える。
- `npm.cmd run verify` と `npm.cmd run smoke:ui` が通る。
- GitHub Pagesで公開URLが確認できる。

## タスク

1. Git初期化とVite/React/TypeScriptの土台作成。
2. 旧版の機能抽出と新しいデータモデルの設計。
3. 座席生成ロジックの純粋関数化。
4. 先生向けワークベンチUIの実装。
5. CSV/JSON/印刷とlocalStorage保存の実装。
6. テスト、ハーネス、運用ファイル、履歴の追加。
7. GitHub public repo作成、push、GitHub Pages公開。

## 2026-05-03 GUIリッチ化

- 生成画像3を採用し、データ量の多い三列コンソールとしてUIを拡張する。
- 既存の席替え生成、出席番号方式、手動入れ替え、CSV/JSON/印刷は維持する。
- 右側に前回/今回/差分の比較サマリーと注意パネルを追加し、結果確認の判断材料を増やす。
- スマホではパネルを縦積みにし、5x6の既定座席表は横スクロールなしでも確認しやすい密度にする。

## 判断理由

- 静的Webアプリにすることで学校端末から扱いやすく、個人情報の外部送信リスクを抑えられる。
- React + TypeScript + Viteは、旧版のCDN/Babel構成より保守しやすく、テストとGitHub Pages公開に向いている。
- 配慮条件は「最適化の重み」として扱い、完全保証ではなく結果を確認して使う設計にする。
- 生成画像3は、先生が生成後に比較・注意・手動調整まで同じ画面で進められるため、現在の機能量と相性がよい。
