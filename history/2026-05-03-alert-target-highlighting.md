# 2026-05-03 ALERTS対象席の視覚化

## 目的

右側のALERTSに注意項目がある場合、先生が座席表上で対象席をすぐ見つけられるようにする。

## 変更

- ALERTSを文字列だけでなく、種類、メッセージ、対象席を持つ構造に変更。
- 履歴から同じ席、同じ隣接、左右ペアの再発対象を座席キーへ復元。
- 空席警告も対象席として扱う。
- 対象席に `alert-target` と種類別classを付け、注意バッジと強調枠を表示。
- ALERTSパネルに対象席ラベルの抜粋を表示。
- UIテストに「警告対象席が座席表でハイライトされる」ケースを追加。

## 検証

- `npm.cmd run verify`: pass
- `npm.cmd run smoke:ui`: pass
- `output/playwright/sekigae-alert-targets.png`: pass、履歴と同じ配置を注入し30席の注意バッジを確認。

## 次の改善

- 対象席をクリックしたとき、対応するALERTS行も右側パネルで強調する。
