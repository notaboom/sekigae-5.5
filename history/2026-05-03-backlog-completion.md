# 2026-05-03 改善バックログ一括対応

## 目的

`TASKS.md` の改善バックログをすべて実装し、先生が席替え案を作った後に調整・説明・保存・公開運用まで迷わず進められるようにする。

## 変更

- 離す児童ペアのルールを追加し、隣接している場合は生成スコアと診断、ALERTS、児童別理由に反映するようにした。
- 教室テンプレートを複数保存・呼び出し・削除できるようにした。
- 比較サマリーの詳細表示で、同席、同隣、左右ペア、離すルールの対象児童と席を表示するようにした。
- ALERTS項目や対象席をクリックしたとき、右側パネルの該当注意を強調するようにした。
- 結果パネルに児童別理由を追加し、配慮達成、再発、離すルールの注意を児童単位で確認できるようにした。
- A4印刷に加えて、座席表のPDFファイルをブラウザ内で生成してダウンロードできるようにした。
- iPad横向き向けに、座席表と座席編集を優先する専用レイアウトを追加した。
- 旧URL移行確認パネルを追加し、この端末の旧キー、新キー、移行済/未移行、履歴件数を確認できるようにした。
- `scripts/verify-sekigae-reflection.mjs` と `npm.cmd run verify:sekigae` を追加し、`/sekigae/` ビルドが利用者向けリポジトリに反映されているか確認できるようにした。

## 確認観点

- 既存localStorageは新しい配列・移行確認情報がなくても起動できる。
- 離すルールは生成、手動入れ替え後の再診断、ALERTS表示に反映される。
- PDF書き出しはサーバー送信なしでファイルを生成する。
- PlaywrightスモークでPC、iPad横向き、スマホのスクリーンショットを取得する。
- `sekigae-5.5` 検証後、`VITE_BASE_PATH=/sekigae/` ビルドを `sekigae` にコピーして `verify:sekigae` を通す。
