# 2026-05-03 手動入れ替えとGUI案探索準備

## 背景

席替えボタンで生成した後、先生が実際の事情に合わせて一部の席を手動調整したい。あわせてGUIをリッチにする検討を始めるため、現行版へ戻れる復元点を先に確保する。

## 実施内容

- 現行版の復元タグ `current-ui-before-rich-gui-20260503` を作成。
- 生成後に席を選択すると、入れ替え先を選んで手動で席を入れ替えられるUIを追加。
- 入れ替え後は現在の座席プラン、履歴内の同一プラン、隣接ペア、診断指標を再計算。
- 固定席と使用不可席は入れ替え対象外にした。
- UIスモークに、生成後の手動入れ替えフローを追加。

## 検証

- `npm.cmd run verify`: pass
- `npm.cmd run smoke:ui`: pass
